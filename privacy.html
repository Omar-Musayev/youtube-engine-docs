Privacy policy

This policy covers the YouTube Engine desktop application and its public documentation site.

Data and permissions

The application uses Google OAuth to access the channel selected by its operator. It checks the channel identifier and retrieves video identifiers, status and metadata, and YouTube Analytics and Reporting data such as views, watch time, impressions, and click-through rates when available. An optional authorization for monetary analytics is available in the desktop tool and is off by default.

When an operator explicitly runs an approved publishing operation, the application sends the video file and its metadata to YouTube. It uses YouTube API data to verify the channel, reconcile upload and publishing status, and review performance. The app uses Google user data for these functions and does not sell it or use it for advertising.

Storage and disclosure

OAuth credentials are stored in access-restricted local files. API results, upload state, and reports may be stored locally in databases or files. Local backups of workflow data can contain API results. The documentation site does not receive OAuth credentials or channel data. The site has no sign-in, analytics scripts, or forms. GitHub Pages may log visitor IP addresses for security as described in the GitHub Privacy Statement.

Revoking access and removing data

To stop access, stop the desktop application and remove its access in Google Account security settings. The current desktop version does not automatically remove previously stored reports after revocation. The operator can delete the app’s local credentials, reports, databases, and relevant backups from their own device. Removing local copies does not remove videos or data stored by YouTube.

Google’s handling of data is described in Google’s Privacy Policy. For assistance with the app or deletion of locally stored data, use the support contact listed on the Google OAuth consent screen.
